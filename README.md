# tallyboard

## Layout

- `web/` — React + TypeScript + Vite frontend (this story).
- `api/` — FastAPI backend, added by later stories.

## Commands (run inside `web/`)

| Purpose | Command |
| --- | --- |
| Install dependencies | `npm ci` |
| Start the dev server | `npm run dev` |
| Production build (minified bundle in `dist/`) | `npm run build` |
| Run tests | `npm test` |
| Run tests with the 80% coverage floor | `npm run test:coverage` |

Requires Node 20 or newer.
