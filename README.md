# tallyboard

## Layout

- `web/` — React + TypeScript + Vite frontend.
- `api/` — FastAPI backend, added by later stories.

## Commands (run in `web/`)

- `npm ci` — install dependencies from the lockfile (setup).
- `npm run dev` — start the dev server.
- `npm run build` — produce a minified production bundle in `web/dist`.
- `npm test` — run the test suite; `npm run test:coverage` measures coverage.

Requires Node 20.19 or newer.
